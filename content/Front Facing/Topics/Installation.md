If you have not done so already, install Houdini Apprentice [here](https://www.sidefx.com/download/). You will need to create a SideFX account. It does not matter what email you use to sign up for the program.

Once logged in, you should be able to download the Houdini Launcher here.![[Front Facing/attachments/downloadHoudiniLauncher.png|Houdini Launcher Download]]
With Houdini Launcher installed, you will see this screen here (without the Houdini version installed).

![[Front Facing/attachments/houdiniLauncher.png|Houdini Launcher]]
Click on Install Houdini at the upper right hand corner as shown.

![[Front Facing/attachments/versionInstall0.png]]
Click on **Choose Another Version**

![[Front Facing/attachments/versionInstall1.png]]
Here, look for
>**Version**: 21.0.440
>**Release Type**: Production
>**Build Type**: Default
---
![[Front Facing/attachments/image.png]]

Make sure **Automatically Install SideFX Labs** is checked on.

Congratulations! You should now have Houdini installed.
